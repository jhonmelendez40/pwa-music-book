# PWA Music Book
Aplicación PWA creada 100% desde celular con Acode y lista para convertir en APK gratis con PWABuilder.

## Funciones
- Login / Registro / Recuperación (localStorage)
- Lista de canciones
- Drag & Drop + soporte táctil
- Vista tipo libro
- Funciona offline con Service Worker

## Cómo ejecutar
1. Abre `index.html`
2. Instala como PWA
3. Funciona completamente offline

## Convertir a APK
- Publica en GitHub Pages
- Ve a https://pwabuilder.com
- Genera el APK gratis
